# 🤖 AI Usage Guidelines - Reflection

## 🔍 Research Summary

### AI tools typically used in a data analytics role
- **ChatGPT / Claude** — explaining code, brainstorming, drafting documentation
- **GitHub Copilot** — code suggestions and autocompletion
- **PostHog AI** — product analytics insights (used at Focus Bear)
- **Jupyter AI** — AI assistance inside Jupyter notebooks
- **Pandas AI** — natural language queries on dataframes

### Benefits of AI in a professional setting
- Speeds up repetitive or boilerplate tasks
- Helps explain unfamiliar concepts or code quickly
- Good for brainstorming and generating first drafts
- Useful for debugging — explaining what an error means
- Reduces time spent on documentation writing

### Risks of AI in a professional setting
- **Hallucinations** — AI can confidently produce incorrect information
- **Data privacy** — entering sensitive data into AI tools can expose it
- **Over-reliance** — not building real understanding of what you are doing
- **Copyright issues** — AI-generated code may reproduce licensed material
- **Bias** — AI outputs can reflect biases in training data

### What should NEVER be entered into AI tools
- User personal data (emails, names, usage data)
- Company confidential information or internal strategies
- Passwords, API keys, or credentials
- Unreleased product details or proprietary code
- Anything covered under Focus Bear's data privacy policy

### How to fact-check and validate AI-generated content
- Cross-reference with official documentation
- Test AI-generated code before using it in production
- Search for the same answer via Google to verify
- Ask a colleague to review if unsure
- Never trust AI output for critical decisions without verification

## 📝 Reflection

### When should I use AI vs. my own skills?
Use AI for:
- Getting unstuck quickly on syntax or concepts
- Generating a starting point or template to build on
- Explaining error messages in plain English
- Drafting documentation or summaries

Rely on my own skills for:
- Understanding the logic and reasoning behind a solution
- Anything involving real user data or confidential information
- Final review and validation of all outputs
- Building genuine expertise — AI should supplement, not replace learning

### How will I avoid over-reliance on AI?
I will treat AI like a search engine with conversation — useful for finding 
direction, but I need to understand and verify everything it gives me. 
I will always read, test, and edit AI output rather than copy-pasting it 
directly. If I cannot explain what the AI-generated code does, I will not use it.

### Steps I will take to ensure data privacy when using AI
- Never paste real user data, API keys, or confidential code into AI tools
- Use anonymised or dummy data when asking AI for help with data tasks
- Check Focus Bear's AI policy before using any new AI tool for work tasks
- Default to asking a colleague instead of AI when the task involves 
  sensitive information

## 🛠️ Task: AI Tool Trial

### Task I improved using AI
I used Claude to help me draft and structure my onboarding markdown reflection 
files. Rather than starting from a blank page each time, I used AI to generate 
a structured first draft which I then reviewed, edited, and personalised with 
my own experiences and knowledge.

### Critical review of AI output
The AI-generated content required editing in several places:
- Some sections were too generic and needed personalising with my actual context
- I had to verify specific facts (e.g. Focus Bear's privacy policy details) 
  rather than trusting AI's general knowledge
- Tone needed adjusting in places to sound more natural and genuine
- Some reflections were replaced entirely with my own observations

### One best practice I will follow at Focus Bear
**Always review and edit AI output before submitting or using it.**

AI is a starting point, not a finished product. Every piece of AI-generated 
content I produce for Focus Bear will be read, fact-checked, and edited by 
me before it is used. I take full responsibility for anything I submit — 
"the AI wrote it" is not an excuse for errors or privacy breaches.
