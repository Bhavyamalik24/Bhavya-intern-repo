# VS Code Productivity - Shortcuts & Reflection

## Top 10 VS Code Shortcuts

### Navigation
| Shortcut | Action |
|---|---|
| `Ctrl + P` | Quick open- search and open any file instantly |
| `Ctrl + Shift + E` | Open Explorer panel to browse files |
| `Ctrl + Tab` | Switch between open files |
| `Ctrl + G` | Go to a specific line number |

### Editing
| Shortcut | Action |
|---|---|
| `Alt + Click` | Add multiple cursors to edit multiple lines at once |
| `Ctrl + D` | Select next occurrence of current word |
| `Ctrl + Shift + L` | Select ALL occurrences of current word at once |
| `Alt + Shift + Down` | Duplicate current line downward |
| `Ctrl + /` | Toggle comment on current line or selection |
| `Ctrl + Z` | Undo last action |

### Debugging
| Shortcut | Action |
|---|---|
| `F5` | Start debugging |
| `F9` | Toggle breakpoint on current line |
| `F10` | Step over — move to next line during debugging |
| `F11` | Step into — go inside a function during debugging |

### Terminal
| Shortcut | Action |
|---|---|
| `` Ctrl + ` `` | Open/close the integrated terminal |
| `Ctrl + Shift + 5` | Split terminal into two panels |
| `Ctrl + C` | Stop a running process in the terminal |

## Reflection

### Which shortcuts will be most useful in my daily work?

**`Alt + Click` (multiple cursors)** is going to be the most valuable by far.
When working with data analytics, renaming columns, editing repeated values,
or updating multiple lines of similar code, being able to place cursors on
multiple lines and type once is a massive time saver.

**`Ctrl + D`** is a close second. Selecting the next occurrence of a word and
editing them one by one is perfect for renaming variables across a file without
a full find-and-replace.

**`` Ctrl + ` ``** will also be used constantly, switching between the code
editor and terminal without leaving VS Code keeps the workflow smooth and
avoids context switching between windows.

**`Ctrl + P`** is essential for navigating large projects quickly without
having to click through folder structures.

### How do keyboard shortcuts improve productivity?

Every time you move your hand from the keyboard to the mouse, you lose a
small amount of time and break your flow. Across a full working day those
small interruptions add up significantly. Keyboard shortcuts keep your hands
on the keyboard and your mind in the code.

More importantly, shortcuts reduce cognitive load, instead of thinking about
where to click, you just act. Over time they become muscle memory, which means
the mechanical parts of coding (navigating, editing, running code) require
almost no conscious thought, freeing up mental energy for the actual problem
you are solving.

For someone like me who is still building coding confidence, shortcuts also
make me feel more in control of my environment, which makes the whole
experience less intimidating and more productive.
