# Basic Python Programming - Reflection

## Tasks Completed

### Task 1: Hello, Python!
Wrote a program that prints a greeting message using `print()`. This was
the first Python program I ran and introduced me to basic syntax — how
Python reads and executes code line by line.

### Task 2: Simple Math
Created a program that takes two numbers as user input and calculates
the sum, difference, product, and quotient. Used `float()` to convert
text input into numbers and added a guard clause to prevent division
by zero.

### Task 3: Age in Dog Years
Built a program that asks for the user's name and age, calculates their
age in dog years (1 human year = 7 dog years), and prints a personalised
message using f-strings and if/elif/else statements.

### Task 4: Favourite Food
Used multiple `input()` calls to collect the user's name, favourite food,
and mood, then generated a fun personalised sentence using f-strings.

### Task 5: Number Guessing Game
Built a simple game where Python generates a random number between 1 and
10 using `random.randint()` and the user has 3 attempts to guess it.
Used a `while` loop, `break`, and if/elif/else statements to control
the game flow.

---

## Reflection

### Which task did you find the most fun?
The number guessing game (Task 5) was the most enjoyable. It felt like
a real program rather than just an exercise — it had a loop, random
numbers, a win condition, and a game over state. Seeing all the concepts
from the earlier tasks come together into something interactive made it
click in a way that isolated exercises don't.

### How did you feel when you saw your code running correctly?
It was satisfying to see the output appear exactly as expected after
writing the code. Even for simple programs, there is a clear sense of
cause and effect — you write instructions, Python follows them precisely.
Each task that ran correctly built confidence to try the next one.

### How could you imagine using these skills to solve problems?
These foundational concepts — input, variables, loops, conditionals, and
random numbers — are the building blocks of almost every Python program.
At Focus Bear specifically, understanding how user input is collected and
processed, how conditions control program flow, and how loops repeat
actions is directly relevant to understanding how the app's data
analytics and habit tracking logic works under the hood. Even simple
automation tasks like processing a CSV file or calculating statistics
use the same core concepts practised here.
