# Chrome Extensions Setup - Reflection

## Extensions Installed

### 1. React Developer Tools
- **What it does:** Adds a React tab to Chrome DevTools (F12) that lets
  you inspect the React component tree of any React application. You can
  see component props, state, and hierarchy in real time.
- **Why I installed it:** Focus Bear's frontend is built with React. This
  tool will be essential for understanding how the UI is structured and
  debugging component-level issues when working on the codebase.

### 2. Redux DevTools
- **What it does:** Adds a Redux tab to Chrome DevTools that lets you
  inspect and debug Redux state changes in real time. You can see every
  action that was dispatched and how the state changed in response.
- **Why I installed it:** If Focus Bear uses Redux for state management,
  this tool will help me understand how data flows through the app and
  debug unexpected state behaviour.

### 3. JSON Viewer
- **What it does:** Automatically formats and syntax-highlights JSON
  responses in the browser, making them readable instead of showing raw
  unformatted text. Makes working with APIs much easier.
- **Why I installed it:** As a data analytics intern I will frequently
  work with API responses and data payloads. Being able to read JSON
  clearly at a glance speeds up debugging and data exploration significantly.

### 4. Lighthouse
- **What it does:** Built into Chrome DevTools (F12 → Lighthouse tab),
  it audits web pages for performance, accessibility, SEO, and best
  practices. Generates a detailed report with scores and improvement
  suggestions.
- **Why I installed it:** Understanding how Focus Bear's web app performs
  is useful context for a data analytics role, performance data can
  inform product decisions and improvements.

---

## Reflection

### Most useful thing I learned
The most useful thing I learned is that Chrome DevTools (F12) is far more
powerful than I realised. I had used it before to inspect page elements,
but I did not know it had dedicated tabs for React components, Redux state,
network requests, performance profiling, and Lighthouse audits all in one
place. These tools turn the browser into a full development and debugging
environment.

### How these extensions will improve my workflow

| Extension | When I will use it |
|---|---|
| React Developer Tools | Inspecting UI components and understanding the Focus Bear frontend structure |
| Redux DevTools | Debugging state changes and understanding data flow in the app |
| JSON Viewer | Reading API responses and data payloads clearly |
| Lighthouse | Auditing page performance and accessibility |

### Key learning
Browser extensions and DevTools are not just for frontend developers, 
as a data analytics intern, understanding how data flows through the
application (via Redux state, API responses, and network requests) gives
me valuable context for the analytics work I will be doing. These tools
help bridge the gap between the frontend and the data layer.
